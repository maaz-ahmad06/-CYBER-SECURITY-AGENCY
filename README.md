# 🛡️ CYBER SECURITY AGENCY

A premium, 100% responsive, high-end cybersecurity landing page website designed with a dark cyberpunk aesthetic, rich micro-animations, dynamic simulated terminal logs, and custom interactive components.

---

## ✨ Features

*   **⚡ Cyber Diagnostic Preloader**: A simulated 2-3 second system-boot sequence that counts to 100% and displays initialization logs before fading out smoothly.
*   **🌐 100% Responsive Design**: Carefully optimized for mobile (375px+), tablet (768px+), laptops, and large screens. Structured with fluid bounds (`clamp`, grid, flex) and zero horizontal scrollbars.
*   **💻 Live Threat Intelligence Terminal**: Mockup console logging simulated global threat alerts, intrusion attempts, and zero-day protection warnings in real-time.
*   **📊 Interactive Counter Animation**: Statistics counters (Mitigation rate, response times, threats blocked) roll up dynamically when scrolled into view.
*   **🖱️ Cursor Glow spotlights**: Service cards track cursor coordinates (`--mouse-x`, `--mouse-y`) to render moving glowing spotlights.
*   **🔒 Encrypted Incident Portal**: Secure intake form that validates user inputs and simulates encrypted data transmission sequences inside a glassmorphic dashboard modal.
*   **💎 Visual Polish**: Dark glassmorphic design (`backdrop-filter`) with glowing cyan and neon green highlights, concentric rotating radar circles, scanning laser lines, and scroll reveal triggers.

---

## 🛠️ Built With

*   **HTML5** - Semantic layout structure.
*   **CSS3 (Vanilla)** - Custom grid structures, variables, cyberpunk variables, and `@keyframes` animations.
*   **JavaScript (ES6+)** - Simulated loops, intersection observers, mouse tracking, and preloader timeouts.

## 🚀 How to Run Locally

Since this is a client-side vanilla codebase, you don't need any complex installation. Just follow these steps:

1.  **Clone the Repository**:
    ```bash
    git clone https://github.com/your-username/CYBER-SECURITY-AGENCY.git
    cd CYBER-SECURITY-AGENCY
    ```
2.  **Run a Local Server**:
    Using Python (pre-installed on most operating systems):
    ```bash
    python -m http.server 8080
    ```
    Or using NodeJS:
    ```bash
    npx http-server -p 8080
    ```
3.  **Open in Browser**:
    Visit `http://localhost:8080` in your web browser.
